# GGR472 Lab 2: Introducing Mapbox GL JS
This repository contains code for a webpage with a link to a GeoJSON file, as required for Lab 2

Webpage URL: https://abordachan.github.io/lab2/

## Key repository Contents
- `data/tennis_courts_facilities.geojson`: Data file containing point locations of Tennis Courts in Toronto 
- `data/parks_drinking_fountains.geojson`: Data file containing point locations of Drinking Fountains in Toronto 
- `index.html`: HTML file to render homepage
- `map.html`: HTML file to render map
- `report.html`: HTML file containing report
- `script.js`: JavaScript file to add map within map.html
- `button.js`: JavaScript file to enable button interactivity within homepage
- `style.css`: CSS file to style map
